# Spin draw

Print a paper disc, pin it to tracing paper, and trace one numbered line
each time you turn the disc. The lines add up to a picture.

Pick a picture, or draw and upload your own. **Lines** sets how many times
you turn the disc. **Play** traces the picture on screen. **Print** sends
the disc to the printer at 170 mm across. **Download SVG** saves the same
disc.

## Trace a printed disc

1. Cut out the circle.
2. Lay tracing paper on top. Pin both sheets through the center hole. Leave
   the tracing paper still.
3. Draw a dot on the tracing paper at the edge of the circle.
4. Turn the circle so 1 meets the dot. Trace the line with the upright 1.
5. Turn so the next number meets the dot and trace that line. Continue
   through the last number.

The picture lands below the pin. Thin paper you can see through works the
same way as tracing paper.

## Run locally

```bash
npm start
```

Open http://localhost:3000. Tests:
